Attack context
  - IMDS-BUILD Cloud metadata reachability during image build. If a builder can reach 169.254.169.254, a malicious Dockerfile can mint temporary cloud credentials from the instance role. Mitigation: block link-local ranges in the build network namespace.
  - SHAI-HULUD-2 Shai-Hulud 2.0 supply-chain build abuse. Malicious packages abuse install and build steps on CI runners to steal tokens and publish further poisoned packages. Mitigation: network-isolated builds, short-lived OIDC tokens, no long-lived secrets in build env.
  - SMITHERY-2025 Smithery MCP build-path leak. A shared MCP build service exposed files outside the project build context, leaking a token with access to 3000+ servers (reported via GitGuardian). Mitigation: builder-side path jail and per-tenant isolation.
